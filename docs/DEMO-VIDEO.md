## YouTube metadata

Title:

Mend: Safe, Verified Website Repairs with WebMCP

Description:

Mend turns website audits into a shared human and agent workflow: scan,
understand, propose, approve, fix, and verify.

In this demo, Mend audits a deterministic website, maps a missing image alt
attribute to source, generates an exact diff, waits for explicit human approval,
creates a safe branch snapshot, and verifies the improvement with zero
regressions.

Live demo: https://mend-webmcp.vercel.app/
Source code: https://github.com/aryansk/mend-webmcp

Mend exposes structured WebMCP tools through `document.modelContext`:
`scan_site`, `get_audit_summary`, `list_issues`, `inspect_issue`,
`compare_audits`, source inspection, `propose_fix`, human approval,
branch-first apply, and verification.

The human stays in control of every source-changing action.
